# Установка на принимающей машине

## 1. Куда положить скиллы

Целевая папка: `Р - Technical - Ai Projects - Ai Skills`.

Ожидаемая структура после установки:

```
Р - Technical - Ai Projects - Ai Skills\
├── skills\
│   ├── market-research\
│   └── market-news\
├── data\
│   └── registries\
└── README.md
```

Скилл-хосты ищут скиллы по-разному:

- **Claude Code**: `%USERPROFILE%\.claude\skills\<имя>\SKILL.md` — папки из `skills/` копируются туда (или создаётся симлинк).
- **ZCode**: `%USERPROFILE%\.zcode\skills\<имя>` — часто это симлинки на `.claude\skills`.
- **Другой хост**: положить папки в свою директорию скиллов, сохранив вложенность `tools/` и `templates/`.

Копирование в `Р - Technical - Ai Projects - Ai Skills\skills\` — это архив-источник, откуда скиллы берутся и запускаются; в хост их нужно либо скопировать, либо сослаться симлинком.

## 2. Куда положить данные

Скиллы ждут рабочую папку:

```
%USERPROFILE%\Documents\ITMO_research_info\Рынок и темы Copilot\
└── 00 Реестры и требования\
    ├── Реестр тем поиска.yaml
    ├── Реестр направлений продуктового поиска.yaml
    └── Требования к поиску по рынку — темы и критерии.md
```

Скопировать туда `data/registries/`. Если папка называется иначе — в каждом `SKILL.md` поправить строку «Папка поиска» (для `market-research` и `market-news`) и путь к реестру.

Остальные подпапки (`04 Продукты — отмеченные направления`, `05 Свежее`, `Тендеры`) скиллы создают сами при первом запуске, но базовые отчёты для сверки «только нового» берутся из `04 …` — если их нет, скилл просто ищет без сверки, это нормально для старта с нуля.

## 3. Зависимости

```bash
python -m pip install pyyaml
```

Проверка готовности:

```bash
python skills/market-news/tools/build_news_prompts.py --show
python skills/market-research/tools/build_prompts.py --show
```

Каждая команда должна вывести список тем с номерами и статусами. Ошибка `ModuleNotFoundError: yaml` — не установлен pyyaml. Ошибка «реестр не найден» — неверный путь в `SKILL.md`.

Скилл поиска тендеров в пакет не входит.

## 4. Word-конвертер (опционально)

Скиллы требуют прогонять `.md` через `md_to_docx_a4.py`. Если скрипта нет:

- либо положить его по пути из `SKILL.md`;
- либо заменить шаг конвертации на пропуск — отчёты останутся в `.md`.

Нужен пакет `python-docx`.

## 5. Проверка полного цикла

```bash
python skills/market-news/tools/build_news_prompts.py --months 3 --dirs P9 --out plan.json
```

Должно вывести окно «с … по …», число направлений и запросов поиска, а в `plan.json` — задания с промптами. Это значит, что реестр читается, шаблоны на месте, инструменты работают.

## 6. Если пути другие

Правки только в `SKILL.md`, блок «Где что лежит». Инструменты пути не содержат — они принимают реестр и папку через аргументы.
