# AI Skills — поиск по рынку (передача)

Набор скиллов для исследований рынка ИИ-продуктов и поиска активных тендеров. Версия от 25.11.2026, источник — рабочая машина владельца.

## Что внутри

| Папка | Что делает | Запуск |
|---|---|---|
| `skills/market-research` | Полное исследование рынка по темам: три волны (отрасль, финансовая привлекательность, инвесторы и закупки) | «сделай исследование рынка по теме …» |
| `skills/market-news` | Свежие новости рынка по направлениям из реестра, строго в окне N месяцев | «что нового на рынке за 3 месяца» |

`data/registries` — реестры тем и направлений и требования к поиску. Без них скиллы не работают: темы, ключи поиска и окно берутся оттуда.

Скилл поиска тендеров в пакет не входит — передаётся отдельно. В реестрах остались комментарии и поле `tender_keys`, относящиеся к нему; на работу скиллов рынка они не влияют.

## Требования

- Python 3.10+ и пакет `pyyaml` (`pip install pyyaml`).
- Для конвертации отчётов в Word — `python-docx` и скрипт `md_to_docx_a4.py` (в пакет не входит, путь настраивается).
- Веб-поиск выполняет агент-хост (Claude Code, ZCode или другой) — сами скиллы интернет не запрашивают.

## Быстрый старт

1. Скопировать содержимое `skills/` в свою папку скиллов (например `Р - Technical - Ai Projects - Ai Skills\skills\`).
2. Скопировать `data/registries/` в рабочую папку исследований, ожидаемую скиллами: `Documents\ITMO_research_info\Рынок и темы Copilot\00 Реестры и требования\`. Если папка называется иначе — поправить путь в `SKILL.md` каждого скилла (одна строка «Папка поиска»).
3. Проверить: `python skills/market-news/tools/build_news_prompts.py --show` должен вывести направления P1–P9.

Подробно — в [INSTALL.md](INSTALL.md). Готовый промпт для агента, который забирает пакет — в [FETCH_PROMPT.md](FETCH_PROMPT.md).

## Важно

- Скиллы по умолчанию спрашивают оператора об окне и темах перед каждым запуском — это правило, а не настройка.
- Правило лимита веб-поиска: при «Rate limit reached» ждать ~90 секунд и повторять тот же запрос до успеха, ничего не пропускать.
- Реестры содержат рабочие темы компании. Репозиторий держать приватным.
