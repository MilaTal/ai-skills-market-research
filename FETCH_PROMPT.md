# Промпт для принимающей машины

Скопировать целиком в чат агента на локальной машине (Claude Code, ZCode или другой хост с доступом к файлам и терминалу). Заменить `REPO_URL_PLACEHOLDER` на адрес репозитория.

---

Забери пакет скиллов поиска по рынку из GitHub и установи его на эту машину.

**Репозиторий:** REPO_URL_PLACEHOLDER
**Целевая папка:** `Р - Technical - Ai Projects - Ai Skills`

Шаги:

1. Найди на дисках папку `Р - Technical - Ai Projects - Ai Skills` (поиск по имени, глубина до 5). Если не нашёл — не создавай наугад, спроси у меня полный путь. Внутри должна появиться структура `skills\` и `data\`.

2. Забери репозиторий во временную папку:
   - если есть `git`: `git clone --depth 1 REPO_URL_PLACEHOLDER "%TEMP%\ai-skills-fetch"`;
   - если git нет: скачай архив `https://github.com/<owner>/<repo>/archive/refs/heads/main.zip` через curl/PowerShell и распакуй.

3. Скопируй в целевую папку: `skills\` (market-research, market-news), `data\registries\`, `README.md`, `INSTALL.md`. Существующие файлы не перезаписывай молча: при конфликте покажи различия и спроси.

4. Проверь окружение: Python 3.10+ и пакет `pyyaml`. Если `pyyaml` нет — `python -m pip install pyyaml`. Для конвертации в Word нужен `python-docx`, но его отсутствие не блокирует установку.

5. Создай рабочую папку скиллов и положи реестры:
   `%USERPROFILE%\Documents\ITMO_research_info\Рынок и темы Copilot\00 Реестры и требования\` ← файлы из `data\registries\`.
   Если у меня уже есть свои реестры — не затирай их, покажи, чем отличаются, и спроси, какие оставить.

6. Подключи скиллы к хосту, определив его сам:
   - Claude Code: скопируй папки из `skills\` в `%USERPROFILE%\.claude\skills\` (или сделай симлинки — предпочтительнее, чтобы обновления из архива подхватывались);
   - ZCode: `%USERPROFILE%\.zcode\skills\<имя>` (обычно симлинк на `.claude\skills`);
   - иначе: положи в директорию скиллов хоста, сохранив вложенность `tools\` и `templates\`.

7. Проверь установку двумя командами:
   `python <путь>\skills\market-news\tools\build_news_prompts.py --show`
   `python <путь>\skills\market-research\tools\build_prompts.py --show`
   Ожидаемо: направления P1–P9 у market-news, темы 1–9 у market-research. Ошибка `ModuleNotFoundError: yaml` — не установлен pyyaml. Ошибка «реестр не найден» — поправь строку «Папка поиска» в соответствующем `SKILL.md`.

8. Отчитайся коротко: путь установки, какие скиллы подключены и куда, вывод двух проверок, что осталось настроить (в частности путь к `md_to_docx_a4.py`, если будешь собирать Word).

Ограничения: репозиторий приватный, его содержимое никуда не публикуй и не отправляй вовне. Скрипты в `tools\` — обычные Python-утилиты без сети; запускай их только на чтение реестров, ничего не удаляй. Если структура репозитория не совпадает с описанной — остановись и покажи, что пришло.
